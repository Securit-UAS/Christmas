# Alps 2026 — V18 The Great Alpine Challenge

V18 extends the existing website with 23 Road Trip challenges, WhatsApp claim links, validation-aware leaderboard and a daily results JSON import/preview flow. Secret Santa login, profile and reveal logic are unchanged.

## Publish
Upload **all files in this directory** to the root of your existing GitHub Pages repository. The site uses `index.html`, `styles.css`, `script.js`, `roadtrip.js`, `roadtrip-challenges.json`, and `roadtrip-results.json`. Existing image assets are included.

The `alps-v16-*` files are archival copies and are *not* used by `index.html`.

Full instructions and JSON format: **ROADTRIP-ADMIN.md**.

## Current limits
WhatsApp cannot attach images or pick a particular group automatically via the sharing link; the daily review remains manual. The results importer previews locally and cannot publish itself. The starter results file is intentionally empty: no scores have been invented.
